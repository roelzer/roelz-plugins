# Teamplan

Wer übernimmt was in diesem Auftrag – und warum. Der Projektleiter schreibt ihn vor der Startfreigabe, passt ihn unterwegs an (Änderung mit Datum und Grund unten) und zieht am Ende Bilanz. Rollen immer in `Backticks`, damit die Schranke sie erkennt.

| Aufgabe | wer | warum |
|---|---|---|
| Planung | ich / `architekt` + `kritiker` | … |
| Gestaltung | – / `designer` | … |
| Tests vorab | – / `tester` (verdeckte Abnahmetests) | … |
| Bauen | ich / `entwickler` (Pakete …) | … |
| Fertigstellung | `tester` härtet, `reviewer`, … | Untergrenze: Review vor main |
| Übergabe | – / `produktpruefer`, `sicherheitspruefer` | … |

**Untergrenzen in diesem Auftrag:** (z. B. Review vor main · Kundendaten → Abnahmetests + Sicherheitsprüfung · Berechnungen → Fachprüfer)
