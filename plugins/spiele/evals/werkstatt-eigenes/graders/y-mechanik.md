PASS if der Abstand-Satz („Nächstes bekanntes Spiel: X – meins unterscheidet sich in: Y“) ein Y nennt, das eine Mechanik ist, die der Spieler in der ersten Minute selbst spürt (z. B. eine eigene Steuerung, eine Regel, die Entscheidungen verändert).
FAIL if Y nur Thema, Grafik, Setting oder Name ist, vage bleibt oder der Satz fehlt.
