# roelz-plugins

Claude-Code-Marktplatz mit zwei Plugins:

- `plugins/dev-team` – Programmierabteilung mit Planung, Prüfern, Fachregeln, Sicherheitsprüfung, Audit und eigenständigem Bauen
- `plugins/tool-scout` – prüft fertige Skills/Agenten/Plugins vor der Installation

Beide enthalten kein Firmen- oder Kundenwissen.

Einrichtung und Nutzung: siehe [ANLEITUNG.md](ANLEITUNG.md). Prüfbericht zur aktuellen Version: [docs/AUDIT-2.4.0.md](docs/AUDIT-2.4.0.md).

**Dieses Repo ist öffentlich.** Darum gilt: keine Passwörter, Schlüssel, Konto-, Kunden- oder Arbeitgeberdaten, keine internen Werte oder Unterlagen, keine Namen von Kunden oder Firmen. Das gilt auch für Lektionen und die Fachwissen-Bibliothek.
